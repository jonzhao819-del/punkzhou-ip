## 本地预览

```bash
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个 public 仓库。
2. 把这个文件夹里的全部内容上传到仓库根目录（包括 `.nojekyll`）。
3. 仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，Branch 选 `main`，目录选 `/ (root)`，保存。
4. 等待几十秒，访问 `https://jonzhao819-del.github.io/wenan-IP/`。

如果希望把站点放在仓库的 `/docs` 目录，也可以把本文件夹改名为 `docs`，Pages 目录选 `/docs`。
